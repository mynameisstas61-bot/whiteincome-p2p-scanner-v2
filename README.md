# WHITEINCOME Scanner — первая версия

Первая рабочая заготовка Telegram Mini App + backend-сканера для межбиржевых криптовалютных связок.

## Что умеет
- Telegram-бот показывает кнопку запуска Mini App.
- В Mini App можно менять рабочий депозит, минимальный спред, активы (USDT, BTC, ETH, SOL) и биржи.
- Backend получает публичные стаканы через CCXT и ищет направление купить дешевле / продать дороже.
- Не использует API-ключи бирж и не совершает сделки.
- Показывает только предварительные возможности: расчёт не включает все расходы на вывод/перевод между биржами, сетевые комиссии, задержки и возможное изменение цены.

## Важно про терминологию
С этой конфигурацией это **межбиржевой spot-сканер**, а не полноценный P2P-сканер объявлений. Выбрано «только криптопереводы», поэтому цены сравниваются по спотовым рынкам. Для настоящего P2P по RUB нужен источник объявлений и конкретные способы оплаты; данные P2P нельзя достоверно заменить обычным стаканом.

## Запуск локально
Требуется Python 3.11+.

```bash
python -m venv .venv
# Windows:
.venv\\Scripts\\activate
# macOS/Linux:
source .venv/bin/activate
pip install -r requirements.txt
```

Скопируйте `.env.example` в `.env` и укажите токен бота:
```env
TELEGRAM_BOT_TOKEN=...
WEBAPP_URL=https://YOUR-USERNAME.github.io/YOUR-REPO/
HOST=0.0.0.0
PORT=8000
```

Запустите backend:
```bash
python app.py
```
В другом терминале:
```bash
python bot.py
```

По умолчанию Mini App пытается получить данные у backend по `https://YOUR-BACKEND/api/opportunities`. Для локальной разработки задайте `API_BASE_URL` в `webapp/config.js`. Для реального использования backend нужно развернуть на публичном HTTPS-хостинге, а `API_BASE_URL` установить в адрес backend.

## GitHub Pages
Содержимое папки `webapp/` можно опубликовать на GitHub Pages. В `webapp/config.js` укажите публичный HTTPS URL backend. GitHub Pages не запускает Python backend.

## Расчёт
- Для каждого рынка загружается стакан.
- Для пары `BASE/USDT` ищутся лучшая цена покупки (ask) на бирже A и лучшая цена продажи (bid) на бирже B.
- Оценка прибыли учитывает введённый депозит и ориентировочную taker fee по умолчанию 0.1% на каждую сторону.
- Результат не гарантирует исполнение по top-of-book: глубина стакана может быть недостаточной.
- Комиссии вывода и сети не включены, потому что они зависят от актива, сети и биржи. Перед решением их нужно проверить отдельно.

## Безопасность
- Не добавляйте API-ключи бирж: сканеру публичных данных они не нужны.
- Не публикуйте Telegram token в GitHub. Храните его в `.env` / переменных окружения.
